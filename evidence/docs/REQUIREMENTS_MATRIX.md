# Requirements matrix

Every row is a requirement Evidence applies, with the official source it came from, checked on 2026-11-07. The table is
generated from `claimevidence/rules.py` with `claimevidence rules --matrix`, so the code and this page cannot drift.

Status means:

- **mandatory**: a statute, rule or official form requires it
- **recommended**: official guidance or common practice, not a requirement
- **internal**: a Claim OS default, labelled as ours (fonts, layout, size limits)
- **unresolved**: the sources conflict or are silent; how Evidence handles it is stated

Local procedures stay local: a county row applies only to that county. Nothing from one county's practice is applied to
another.

## Superseded or conflicting sources

| Source | Problem | What Evidence follows |
|---|---|---|
| DOR Uniform Policies and Procedures Manual, August 2025 | prints rule 12D-9.020 before the 2026 amendments (effective 2026-11-02) and 12D-9.025 before 2026-08-27 | the 2026 rule text in the September 29, 2026 Cabinet agenda and the coded rule text |
| Rule 12D-9.015(7) | still says a $15 fee; s. 194.013 allows up to $50 since 2025-07-01 | the statute (File's concern) |
| Evidence exchange before 2025-09-01 | the property appraiser exchanged only on request, 7 days before | 15 days before the hearing for both sides, no request needed |
| DOR brochure PT-101 (rev. 8/25) | says evidence may still be accepted without exchange | exchange is treated as mandatory; the 2026 rules removed that protection |
| Bay VAB 2020 information booklet | $15 fee, optional exchange, the old Axia portal | used only for its note on later sales; the 2026 portal is JustAppraised |
| DOR bulletin PTO 08-02 (2008) on later sales | found only on the Broward appraiser's site; currency unknown | later sales are disclosed and never used to set the value |

## Not verifiable, so marked unknown

Font, margin and PDF-standard rules (none found); county portal file-type and size limits; the number of hearing copies
in Bay (DR-481 leaves it to the county); the Bay property appraiser's preferred exchange method; Bay's 2026 hearing
schedule and TRIM mailing date; whether VAB exhibits are public records; any AI-disclosure rule (none found).
