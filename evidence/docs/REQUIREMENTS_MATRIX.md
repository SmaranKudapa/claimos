# Requirements matrix

Every row is a requirement Evidence applies, with the official source it came from, checked on 2026-11-07. The table is
generated from `claimevidence/jurisdictions/florida/rules.py` with `claimevidence rules --matrix`, so the code and this page cannot drift.

Status means:

- **mandatory**: a statute, rule or official form requires it
- **recommended**: official guidance or common practice, not a requirement
- **internal**: a Claim OS default, labelled as ours (fonts, layout, size limits)
- **unresolved**: the sources conflict; how Evidence handles it is stated
- **unknown**: no source could be found or opened; nothing is assumed

Local procedures stay local: a county row applies only to that county. Nothing from one county's practice is applied to
another.

## Not verifiable, so marked unknown

Font, margin and PDF-standard rules for in-person hearings (none found); Bay's and Hendry's evidence delivery method,
upload limits and hearing copies (DR-481 leaves the number to the county); Bay's JustAppraised evidence upload; Bay's
2026 hearing schedule and TRIM mailing date; whether VAB exhibits are public records outside Palm Beach and Lee; any
AI-disclosure rule for VAB proceedings (none found; court Rule 2.515 applies to courts only).
